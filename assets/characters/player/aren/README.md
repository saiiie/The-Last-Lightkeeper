# Aren assets

`idle/` contains four 64×64 gameplay frames and the existing 256×64 sheet (down, up, left, right). `aren_idle_frames.tres` uses the individual frames. No walk frames exist. `references/` and `previews/` are design/review material only.

The original pack README is preserved verbatim as `source_readme.md`; its old paths are historical. Its review-draft status predates the current request identifying these assets as approved. Side-facing equipment asymmetry remains a documented visual review concern.


# The Last Lightkeeper

> **🚧 Coming Soon**

*A story-driven, top-down 2D action-adventure game.*

## About the Game

**The Last Lightkeeper** is a dark fantasy adventure set in a world consumed by a mysterious darkness.

As the last surviving Lightkeeper, players must explore forgotten regions, battle corrupted creatures, uncover hidden secrets, and restore ancient beacons to bring light back to the world.

But as the journey unfolds, a deeper mystery emerges: **What if the Lightkeepers themselves were responsible for the darkness?**

The game combines exploration, combat, and narrative-driven progression, where every discovery brings players closer to uncovering the truth.

## Tech Stack

- **Engine:** Godot 4
- **Language:** GDScript
- **Platform:** Desktop
- **Genre:** Action-Adventure, Mystery, Exploration
